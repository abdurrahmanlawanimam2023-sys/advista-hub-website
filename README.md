# AdVista Hub website

Website for AdVista Hub: Home, About Us, Services and Contact Us pages.
Plain HTML, CSS and JavaScript. No build step.

## Files
- `index.html` page structure
- `style.css` colours, layout and hover effects
- `script.js` page switching, sliders and the content lists at the top (team, testimonials, recognition, projects, contact details)
- `images/` logo, team photos, testimonial photos, recognition pictures and project logos

## Run
Open `index.html` in a browser.

## Publish free on GitHub Pages
Repository Settings, then Pages, then choose the `main` branch and the root folder.
